# TestFlight: What to Test, build 66

This is Release 1.3.2. The release script uses the git commit count as the iOS
build number.

## English

```text
FJELIAPRO
- Open Settings → FjeliaPro. Check that the subscription options, purchase, restore and Manage Subscription actions respond correctly in the Apple sandbox.
- Check Pro analysis tools on Plan and the AI coach's athlete memory cards. Confirm that saved memories can be edited and deleted.
- If available, check the morning plan proposal after sync and its notification/action. It should reflect today's readiness and planned sessions.

TRAINING & ACTIVITIES
- Check the updated Plan cards, training-load history, weekly load and sport statistics for the correct date range and units.
- Record an indoor row or Concept2 PM5 SkiErg workout. SkiErg is saved as Nordic skiing; check the workout details and activity list.
- Open an activity with ECG data. Check the ECG details, timeline and activity context.

DESIGN & SETTINGS
- Check the refreshed weather screen and the DarkFjelia and LightFjelia themes.
- Settings → System → Developer should be hidden in this TestFlight build.

Please report anything that looks wrong via the feedback button on Home.
```

## Deutsch

```text
FJELIAPRO
- Einstellungen → FjeliaPro öffnen. Prüfe, ob Abo-Optionen, Kauf, Wiederherstellung und „Abo verwalten“ in Apples Sandbox reagieren.
- Prüfe die Pro-Analysen im Plan und die Athleten-Merkkarten des KI-Coachs. Gespeicherte Merkpunkte sollten bearbeitet und gelöscht werden können.
- Falls verfügbar: Prüfe nach dem Sync den morgendlichen Planvorschlag und seine Benachrichtigung/Aktion. Er sollte die heutige Bereitschaft und geplanten Einheiten berücksichtigen.

TRAINING & AKTIVITÄTEN
- Prüfe die überarbeiteten Plankarten, den Belastungsverlauf, die Wochenbelastung und Sportstatistiken auf Zeitraum und Einheiten.
- Zeichne Indoor-Rudern oder ein Concept2-PM5-SkiErg-Workout auf. SkiErg wird als Langlaufen gespeichert; prüfe Details und Aktivitätsliste.
- Öffne eine Aktivität mit EKG-Daten. Prüfe EKG-Details, Zeitlinie und Aktivitätskontext.

DESIGN & EINSTELLUNGEN
- Prüfe die überarbeitete Wetteransicht und DarkFjelia sowie LightFjelia.
- Einstellungen → System → Entwickler sollte in diesem TestFlight-Build ausgeblendet sein.

Bitte melde Fehler über den Feedback-Knopf auf Home.
```
